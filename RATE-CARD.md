# Rate card

Daily rate is set by the car's model year. Two exceptions.

| Year | Daily rate |
|------|-----------|
| 2015 | $65.95 |
| 2016 | $66.95 |
| 2017 | $67.95 |
| 2018 | $68.95 |
| 2019 | $69.95 |
| 2020 | $70.95 |
| 2021 | $72.95 |
| 2022 | $73.95 |
| 2023 | $74.95 |
| 2024 | $75.00 |
| 2025 | $76.00 |
| 2026 | $77.00 |

**Exceptions**

- A **2015 Nissan Versa** is **$65.25**.
- A **2022 SUV** is **$74.95**, not $73.95. Older SUVs take their year's rate.

**Applies to new rentals only.** Renters on a live Stripe subscription keep the
rate they started on until that subscription ends — nobody's price moves
mid-rental.

Cars priced from this card carry `rate_source = 'ratecard'`. Anything still
showing `billing` was priced from what it actually invoiced, and anything
showing `placeholder` has never been set.
